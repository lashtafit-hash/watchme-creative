# WATCH•ME CREATIVE

Одностраничный сайт креативного digital-агентства WATCH•ME CREATIVE.

## Файлы
- `index.html` — сайт целиком: интро из частиц, переключатель EN/RU, услуги (пакеты), кейсы, процесс, контакт.
- `assets/` — изображения. `assets/hero-founder.jpg` используется как превью ссылки (Open Graph).

## Публикация
Сайт статический и публикуется через GitHub Pages из ветки `main` (корень репозитория).
