# WATCH•ME CREATIVE

Сайт на основе предоставленного HTML.

## Файлы
- `index.html` — лендинг со всеми разделами, прайсом, интерактивами и формой обращения в Telegram.
- `assets/` — изображения для карточек услуг (загружены и подключены).

## Соответствие фотографий
- `assets/carousels.jpg` — карусели
- `assets/guides.jpg` — гайды
- `assets/ai-video.jpg` — AI-видео
- `assets/websites.jpg` — сайты
- `assets/quizzes.jpg` — квизы
- `assets/gamification.jpg` — геймификация
- `assets/funnels.jpg` — воронки
- `assets/ai-assistants.jpg` — AI-помощники
- `assets/funnels-alternative.jpg` — запасной визуал

В `index.html` пути изображений прописаны и соответствующие JPG присутствуют в `assets/`. Hero и финальный фон пока оставлены на CSS-заглушках.

## Публикация
Сайт статический. Для GitHub Pages нужен репозиторий с `index.html` и `assets/` в корне. Перед публикацией проверить фото, ссылки Telegram, а также работу колеса и калькуляторов.
